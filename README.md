📊 SQL – Estudos e Práticas

🔍 Consultas simples e avançadas (SELECT)

🔗 Joins (INNER, LEFT, RIGHT, FULL)

📑 Subconsultas e CTEs (Common Table Expressions)

📈 Funções de agregação (SUM, COUNT, AVG, MAX, MIN)

🔧 Manipulação de dados (INSERT, UPDATE, DELETE)

🗂️ Agrupamentos e filtros (GROUP BY, HAVING, WHERE)

🕐 Manipulação de datas, textos e números

💡 Análises de vendas, faturamento, estoque e comportamento de clientes
